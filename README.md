Week 2 - Day 2: Responsive Design

-->Project Overview

This project focuses on creating a responsive, mobile-first landing page using HTML5 and modern CSS techniques.
The website is designed to provide a consistent and user-friendly experience on mobile phones, tablets, laptops, and desktop screens.

-->Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Chrome DevTools

-->Page Sections

The landing page consists of the following sections:

* Navigation Bar
* Hero Section
* Features Section
* Testimonials Section
* Footer

## Responsive Design

A mobile-first approach was followed to make the website adaptable to different screen sizes.
The following breakpoints were implemented:

* **320px** – Small mobile screens
* **768px** – Tablet screens
* **1024px** – Desktop screens
* **1440px** – Large desktop screens

## CSS Grid

CSS Grid is mainly used to organize the feature cards.

The number of columns changes based on the available screen width:

-- Mobile:  1 column
-- Tablet:  2 columns
-- Desktop: 4 columns

-->Flexbox

Flexbox is used to arrange and align different elements, including:

* Navigation bar
* Navigation links
* Hero content
* Testimonial cards
* User profile information

--> Accessibility

The project includes several accessibility and usability considerations:

* Semantic HTML5 elements
* Responsive viewport settings
* Reduced-motion support
* Simple and clear navigation
* Readable text and typography

--> Learning Outcome

This project helped develop practical knowledge of responsive web development. It provided experience in using CSS Grid, Flexbox, media queries, 
mobile-first design principles, and Chrome DevTools to create layouts that adapt to different screen sizes.
